# 画面与逐帧验收

## 尺寸与字形

画布为 1080×1080，30 fps。黑色顶栏高 160 px，下沿有 5 px 黄色分隔线。左右栏各留 150 px，标题对齐整幅画面的水平中心。标题宜控制在一行，按 744 px 可用宽度排版，字号下限 54 px。若仍放不下，制稿时缩短问题。

| 元素 | 字体和字重 | 字号 / 行高 | 颜色与效果 |
|---|---|---|---|
| 情景 / 记单词，两行 | 简体楷体，700 | 38 / 52 px | 灰白 #D8D8D8 |
| 居中情境问题 | 简体楷体，700 | 默认 64 / 76 px | 白字，深灰 1 px 描边，向下 2 px 轻阴影 |
| 四级 / 六级 / 雅思，三行 | 简体楷体，400 | 34 / 48 px | 金黄 #FFD400 |
| 简体正文 | 苹方简体，600 | 默认 39 / 89 px | 左右各留 49 px |
| 英文目标项 | Helvetica Neue，700 | 随正文字号 | 常态黄底 #F9DA4A，朗读中 #E9B82A |
| 词下释义 | 苹方简体，600 | 26.62 / 32 px | 红色 #A2362F，无描边 |

macOS 首选 Kaiti SC、PingFang SC。Linux 可安装 AR PL UKai CN、Noto Sans CJK SC；替代字体的字形可能不同，按最终成片验收。

## 释义锚点

先让正文按英文空格自然换行，再按每行实际容纳的英文组成高亮片段。每个目标项只有最末片段承载一条释义，释义与该片段水平居中。同一行时对应整个短语，跨行时对应末行的全部英文。目标中心误差 ≤2 px，黄底下沿与红字可见像素的间距为 3–6 px。

## 错位复盘和回归

旧样片首词朗读时底栏正确，红字却出现在正文中部。旧实现依赖段落级绝对坐标和渲染期位置回填，默认位置可落在段落中心。具体触发该帧的浏览器时序未单独复现。旧验收只核对八个释义全部出现的画面，漏掉了前面发生的错位。

现实现用固定宽度的正文测量断行，渲染等字体和分行完成，再由英文高亮片段直接定位红字。以最终 MP4 为准：

1. 在每个词首次朗读的帧中，找出深黄色高亮的末行及其水平中心。根据正文末帧红字确定对应释义的实际像素区，检查中心偏差与上下间距。
2. 日常出片默认使用 `sampled`。每个词选择出现前一帧、出现当帧、朗读中点、朗读最后一帧、高亮结束后的第一帧，再加正文首尾。八个词通常覆盖 42 个不同的正文帧。重合帧只查一次，超出正文的帧舍去。
3. 调整模板、字体或排查错位时，运行制片命令并加 `--qa-mode full`，从正文第 0 帧查到正文末帧。两种模式均按时间轴核对读前隐藏、当帧出现、出现后保留及区域外红字，另行检查音轨、完整解码和两张复习卡。
4. 离线回归需实际渲染一个自然跨行的多词短语，验证高亮跨两行且释义只出现在末行中心；同时运行普通样稿。查看验收记录中的 annotationQA，含模式、实际检查帧数、正文总帧数和各词的高亮行数、中心偏差及间距。抽查模式另外列出从 0 开始的实际帧号。
